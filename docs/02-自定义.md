## 一、改配色（1 分钟）

找到 `<style>` 里的 `:root`，改这几个值：

```css
:root{
  --bg:#0d1117;        /* 页面底色 */
  --bg-sub:#161b22;    /* 卡片底色 */
  --fg:#e6edf3;        /* 主文字 */
  --fg-muted:#8b949e;  /* 次要文字 */
  --border:#30363d;    /* 边框 */
  --accent:#58a6ff;    /* 链接、主按钮 */
  --green:#3fb950;     /* 成功 / 开启 */
  --red:#f85149;       /* 危险 / 删除 */
}
```

**改完立刻全站生效** —— 因为所有组件都引用变量，没有写死的颜色。

## 二、加一个菜单项（3 分钟）

菜单就是一个数组，找到它，加一项：

```js
var MENU = [
  {h:'#/',        i:'🏠', t:'首页'},
  {h:'#/repos',   i:'📦', t:'我的仓库'},
  {h:'#/stars',   i:'⭐', t:'我的 Star'},
  // ↓ 新增
  {h:'#/mytools', i:'🛠', t:'我的工具'}
];
```

**然后写对应的渲染函数并注册路由：**

```js
function renderMyTools(){
  document.getElementById('app').innerHTML =
    '<h2>🛠 我的工具</h2><p>这里放你想要的东西</p>';
}

// 加到路由表最前面（越靠前优先级越高）
ROUTES.unshift([/^#\/mytools$/, renderMyTools]);
```

刷新，点菜单就能进。**不需要改任何别的地方。**

## 三、加一个页面（10 分钟）

照抄这个骨架：

```js
function renderMyPage(){
  var host = document.getElementById('app');

  // ① 先占位，避免"点了没反应"
  host.innerHTML = '<div class="empty"><div class="spinner"></div>加载中…</div>';

  // ② 取数据
  gh('/user/repos?per_page=100&sort=updated').then(function(repos){

    // ③ 渲染（记得 esc！）
    host.innerHTML =
      '<h2 style="margin:0 0 12px">📊 仓库概览</h2>' +
      '<div class="card">' +
        '<div style="padding:14px">共 ' + repos.length + ' 个仓库</div>' +
      '</div>' +
      repos.map(function(r){
        return '<div class="card" style="margin-top:8px;padding:12px">' +
          '<a href="#/repo/' + esc(r.full_name) + '">' + esc(r.name) + '</a>' +
          '<div class="muted" style="font-size:12px">' +
            (r.language ? '· ' + esc(r.language) + ' ' : '') +
            '· ⭐ ' + r.stargazers_count +
          '</div></div>';
      }).join('');

  }).catch(function(e){
    host.innerHTML = '<div class="errbox">加载失败：' + esc(e.message) + '</div>';
  });
}

ROUTES.unshift([/^#\/mypage$/, renderMyPage]);
```

**三个不要忘**：`esc()` 转义、先占位、`.catch()` 兜底。

## 四、加一个快捷按钮（5 分钟）

在页面顶部按钮区插一个，用**事件委托**接住点击：

```js
// 渲染时
'<button class="btn" id="myBtn">✨ 一键整理</button>'

// 绑定（页面渲染完之后）
var b = document.getElementById('myBtn');
if (b) b.onclick = function(){
  this.disabled = true; this.textContent = '处理中…';
  gh('/user/repos?per_page=100').then(function(rs){
    alert('你有 ' + rs.length + ' 个仓库');
  }).finally(function(){
    b.disabled = false; b.textContent = '✨ 一键整理';
  });
};
```

> 如果这个按钮在**会被重绘的列表里**，就必须用委托（见 01 章 1.5 节）。
> 只在页面顶部、不参与重绘的按钮，可以直接 `onclick`。

## 五、改列表长什么样（15 分钟）

以 Issue 列表为例，渲染函数长这样：

```js
el.innerHTML = list.map(function(is){
  return '<li class="rowitem">' +
    ghStateIcon(is.state === 'open' ? 'open' : 'closed') +   // 状态图标
    '<div class="body">' +
      '<div class="t"><a href="#/repo/'+esc(full)+'/issues/'+is.number+'">'+
        esc(is.title)+'</a></div>' +
      '<div class="sub">#'+is.number+' · '+ago(is.created_at)+'</div>' +
    '</div>' +
  '</li>';
}).join('');
```

**想加字段，就在 `sub` 那行拼进去。** 接口已经返回了这些，直接用：

| 字段 | 含义 |
|---|---|
| `is.comments` | 评论数 |
| `is.labels[]` | 标签（含 `color`，可还原 GitHub 配色） |
| `is.assignees[]` | 指派人（含 `avatar_url`） |
| `is.milestone` | 里程碑 |
| `is.reactions.total_count` | 表情反应数 |
| `is.updated_at` | 最后更新时间 |
| `is.locked` | 是否锁定 |
| `is.state_reason` | `completed` / `not_planned` / `reopened` |

**标签徽章的写法**（还原 GitHub 真实颜色）：

```js
'<span style="background:#'+l.color+'22;color:#'+l.color+';'+
 'border:1px solid #'+l.color+'55;padding:0 7px;border-radius:2em;font-size:11px">'+
 esc(l.name)+'</span>'
```

> `color` 是 6 位十六进制（无 `#`）。加 `22` 做 13% 透明底，`55` 做边框。

## 六、加一个设置项（10 分钟）

存在 `localStorage`，下次打开自动生效：

```js
// 读（带默认值）
function getCfg(k, dflt){
  try {
    var v = localStorage.getItem('cfg_' + k);
    return v === null ? dflt : JSON.parse(v);
  } catch(e){ return dflt; }
}
// 写
function setCfg(k, v){
  try { localStorage.setItem('cfg_' + k, JSON.stringify(v)); } catch(e){}
}

// 用
var autoRefresh = getCfg('autoRefresh', false);
setCfg('autoRefresh', true);
```

开关按钮：

```js
'<label style="display:flex;gap:8px;align-items:center">' +
  '<input type="checkbox" id="cbAuto"' + (autoRefresh ? ' checked' : '') + '>' +
  '自动刷新</label>'

// 绑定
document.getElementById('cbAuto').onchange = function(){
  setCfg('autoRefresh', this.checked);
};
```

## 七、加一整套主题切换（20 分钟）

```js
var THEMES = {
  dark:   {'--bg':'#0d1117','--bg-sub':'#161b22','--fg':'#e6edf3',
           '--fg-muted':'#8b949e','--border':'#30363d','--accent':'#58a6ff'},
  light:  {'--bg':'#ffffff','--bg-sub':'#f6f8fa','--fg':'#1f2328',
           '--fg-muted':'#656d76','--border':'#d0d7de','--accent':'#0969da'},
  oled:   {'--bg':'#000000','--bg-sub':'#0d0d0d','--fg':'#e6e6e6',
           '--fg-muted':'#7d7d7d','--border':'#212121','--accent':'#4493f8'}
};

function applyTheme(name){
  var t = THEMES[name] || THEMES.dark;
  for (var k in t) document.documentElement.style.setProperty(k, t[k]);
  setCfg('theme', name);
}

// 启动时
applyTheme(getCfg('theme', 'dark'));
```

切换 UI：

```js
Object.keys(THEMES).map(function(n){
  return '<button class="btn" data-theme="'+n+'">'+n+'</button>';
}).join('')

// 委托绑定
document.addEventListener('click', function(e){
  var t = e.target;
  while (t && t !== document){
    var th = t.getAttribute && t.getAttribute('data-theme');
    if (th){ applyTheme(th); break; }
    t = t.parentNode;
  }
});
```

## 八、接自己的 AI（30 分钟）

如果你想加"AI 总结这个 Issue"之类的功能：

```js
function aiChat(messages){
  return fetch(AI_ENDPOINT, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + AI_KEY      // ← 用户自己填
    },
    body: JSON.stringify({ model: 'gpt-4o-mini', messages: messages })
  }).then(r => r.json())
    .then(d => d.choices[0].message.content);
}
```

**⚠️ 三条硬性安全要求：**

1. **AI 密钥绝不写进代码**，让用户自己在页面里填
2. **页面必须跑在 HTTPS 下**，否则密钥明文传输
3. **不要把仓库内容发给不信任的端点** —— 私有仓库内容会泄露

密钥存储：只在内存变量里，**不要** `setCfg()` 存进 localStorage
（localStorage 会被同源的任何脚本读到）。

## 九、调试技巧

**① 看 API 还剩多少额度**

```js
gh('/rate_limit').then(r => console.log(r.rate.remaining + '/' + r.rate.limit));
```

**② 抓真实返回的字段**

不确定接口返回什么？先打印出来：

```js
gh('/repos/o/r/issues/1').then(x => console.log(JSON.stringify(x, null, 2)));
```

**③ 常见错误码**

| 码 | 意思 | 怎么办 |
|---|---|---|
| 401 | 令牌失效/被吊销 | 重新生成 |
| 403 + 0 remaining | 额度用完 | 等一小时，或换令牌 |
| 404 | 没权限 或 真不存在 | 私有仓库要 `repo` 权限 |
| 422 | 参数错 / 写文件没带 `sha` | 检查 body |
| 409 | 空仓库 | 先建个文件 |

## 十、发布

**方式一：单文件直接发**
把 html 发给别人，双击就能用。

**方式二：GitHub Pages**
仓库里放 `index.html` → Settings → Pages → 选 `main` 分支。
拿到 `https://用户名.github.io/仓库名/`。

**方式三：任意静态托管**
Netlify / Vercel / Cloudflare Pages，拖进去就行。

> **发布前必做**：全文搜索 `ghp_`、`github_pat_`、`sk-`，
> 确认一个都没有。**内置令牌 = 把账号送人。**
