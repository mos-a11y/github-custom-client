# 04 · 令牌安全（必读）

**令牌 = 你账号的密码。** 拿到令牌的人可以做你令牌权限内的任何事，
包括**删掉你所有仓库**。这一章请认真看完。

---

## 一、绝对不能做的事

| ❌ | 后果 |
|---|---|
| 把令牌写进 HTML / JS 里 | 任何人"查看源代码"就能看到，等于公开你的账号 |
| 把令牌提交到 Git 仓库 | 即使后来删了，**历史记录里永远在**，还有机器人专门扫 |
| 把令牌发给 AI / 贴进聊天记录 | 不可控，可能被记录、被索引 |
| 令牌放进 URL 参数 | 会被浏览器历史、服务器日志记下来 |
| 用 `repo` 全权限的令牌做只读的事 | 泄露时损失最大化 |

## 二、正确做法

### ✅ 让用户自己填

```js
var TOKEN = '';
// 页面里放一个输入框，用户填完只存内存 + localStorage
localStorage.setItem('gh_token', t);   // 只在本机，不会上传
```

**关键点**：令牌留在**用户自己的浏览器**里。
你的页面只是"借"它去请求 GitHub，不经过你的服务器 —— 因为根本没有服务器。

### ✅ 最小权限原则

只勾真正需要的：

| 你想做什么 | 需要什么 |
|---|---|
| 只看公开仓库 | **什么都不勾**（未登录 60/h，或勾 `public_repo`） |
| 读写自己的仓库 | `repo` |
| 读写 Gist | `gist` |
| 看通知 | `notifications` |
| 触发 Actions | `workflow` |
| 管理 SSH 密钥 | `admin:public_key` ⚠️ 高危，别乱勾 |

### ✅ 设置过期时间

GitHub 现在支持 **Expiration**，选 30/90 天。到期自动失效。
长期项目用 **fine-grained token**（细粒度令牌），可以精确到"只能读某几个仓库"。

### ✅ 定期轮换

像换密码一样，几个月换一次。旧的立刻 `Delete`。

## 三、如果已经泄露了

**立刻做这三步，顺序别乱：**

```
1. 去 https://github.com/settings/tokens
   找到那个令牌 → Delete / Revoke（不是"重新生成"，是删除）

2. 检查有没有被干坏事
   https://github.com/settings/security-log
   看有没有你不认识的登录 / 新加的 SSH 密钥

3. 检查仓库有没有被塞东西
   看最近的 commit，有没有陌生作者
```

> **GitHub 有自动扫描**：如果你不小心把令牌提交到了公开仓库，
> GitHub 会自动吊销它并发邮件给你。但**别指望这个**，自己先删。

## 四、前端存储令牌的风险（说清楚）

`localStorage` 里的令牌：

| 风险 | 说明 |
|---|---|
| 同源脚本可读 | 任何在该域名下运行的 JS 都能读到 |
| XSS 会偷走 | 页面如果有 XSS 漏洞，令牌就没了 |
| 不会自己消失 | 不清缓存就一直在 |

**缓解办法**：

1. **所有用户输入必须转义**（见 01 章的 `esc()`）—— 这是防 XSS 的根本
2. 提供**一键退出**，点了就 `localStorage.removeItem('gh_token')`
3. 敏感操作（删仓库）前**再确认一次**
4. 不要用 `innerHTML` 渲染不可信 HTML；要渲染 Markdown 就先做转义

**坦白讲**：单文件静态页面在安全性上有天然上限。
**个人自用完全没问题**，但如果要给很多人用、且涉及私有仓库，
正确的做法是加一个后端做 OAuth —— 那是另一个量级的工程了。

## 五、自检清单

发布你的客户端之前，跑一遍：

```
[ ] 全文搜索 ghp_        → 0 结果
[ ] 全文搜索 github_pat_ → 0 结果
[ ] 全文搜索 sk-         → 0 结果（AI 密钥）
[ ] 全文搜索自己的用户名硬编码 → 应该没有
[ ] .gitignore 里有 .env / config.local.js
[ ] 页面有"退出登录"按钮，且点了真会清掉令牌
[ ] 所有渲染用户输入的地方都过了 esc()
```

命令行版：

```bash
grep -rn "ghp_\|github_pat_\|sk-" . --include="*.html" --include="*.js"
# 有输出就是有问题
```

## 六、关于本项目

本项目所有文件**不含任何真实令牌**，也不需要你提供令牌就能阅读。

`mini-client.html` 里令牌输入框默认是空的，由使用者自己填写，
只存在他自己浏览器的 localStorage 中。

如果你在自己的二次开发版本里内置了令牌 —— **请立刻删除它并吊销**。
